# Tin Hat play contract v1: views, frames, HTTP (the CONTRACT FREEZE)

Frozen Thu 2026-11-19 by games-s1, from GAMES-V1-SPEC.md §4.3, §5.3 and §6. This folder is byte-identical in every
repo that copies it (`INDEX.json` = the md5 of every file). Generated by the server repo's
`api/tinhat-api/play/contract/build.mjs` through the server's own view code (`play/views.mjs`), so the fixtures are
exactly what the server sends. **Changes after the freeze are additive only** (a new optional field, a new frame type)
and announced in the PM relay; nothing here is renamed or removed in v1.

| file | what |
|---|---|
| `schema.json` | JSON Schema (2020-12 subset) of every frame, view and HTTP answer. It describes EXACTLY what a v1 server sends (no extra fields). `x-codes` = every error code → HTTP status; `x-moves` = every move per game. |
| `holdem/NN-step.json`, `rig/NN-step.json` | one file per phase: `views` = the view of each person in that step (`spectator` = the public view, no `you`), `people` = who is who, `moves` = what each person may send there, `next` = the step a move leads to (the mock plays these). |
| `frames.json` | an example of every socket frame, client and server |
| `http.json` | every HTTP endpoint with a request and an answer |
| `errors.json` | every code: HTTP status + when it happens |
| `cards.json` | the chat cards: event content + the exact plain-text bodies (never any amounts), the hidden-Rig line, the Whisper templates |
| `malformed.json` | `cases`: views/frames an app's parser must REJECT (a known field broken); `tolerated`: what an app must ACCEPT and ignore (an unknown field or frame type) though the server never sends it |

## Rules for the apps
- **The schema is the producer contract** (strict: exactly what a v1 server sends; the server's tests and the mock
  check every frame against it). **Apps parse tolerantly:** ignore unknown fields and unknown frame types, reject a
  known field with a wrong type or value (`malformed.json`). Keep only the newest `vseq` per table; every `view` is a
  full snapshot (never a patch).
- **`live` frames** (The Rig's dial) carry the `vseq` of the view they belong to: apply one only if its `vseq` equals
  the newest view you hold (a newer view replaces it; an older `live` is dropped). The next `view` always carries the
  dial too, so a reconnect needs nothing else.
- `at` is compared field by field (`hand` + `turn`, or `round` + `spin` + `phase`), never as text.
- **Times** are server milliseconds (`deadline`, `next_at`, `at`); each view carries the server's `now`, so draw
  countdowns from `deadline − now` (corrected for when the frame arrived), never from your own clock alone.
- **`legal` is the server's word** (Hold'em): the apps never compute legality. `legal` is `null` unless it's your turn.
- **`you` exists only in your own view.** A spectator's view has no `you`.
- The first socket frame is `auth` (the session never goes in a URL). Ping every 20 s (`pong` answers; 60 s of
  silence = dropped). ≤ 4 sockets per person (the oldest gets `bye replaced`).
- Every `act` except The Rig's `dial` gets an `ack`. Give every act a fresh `op` (16–32 of `[A-Za-z0-9_-]`); a resend
  of the same `op` returns the first answer with `dup: true`, so resending after a reconnect is always safe.
- Moves that belong to a turn carry `at` (Hold'em `{hand, turn}` from `hand.n` + `hand.to_act.turn`; The Rig
  `{round, spin, phase}` from `round.r`, `round.spin`, `round.phase`). Table-level moves (`sit`, `leave`, `deal`, `away`,
  `kick`, `close`, `join`, `start`) carry none. A move for another turn is refused `stale`.
- **Discovery results that are the app's own** (never server codes): `owner-unsupported` (the owner's well-known has
  no `features.play: true`) and `owner-unavailable` (can't reach it). Show them; never guess.
- **History answers** (`/hands`, `/rounds/{r}`, `/summary`, a table's `end`): a person who deleted their chips is
  "someone": a placeholder `~1`, `~2`… local to that one answer (two deleted people stay two). Live views never have one.
- **`wallet` frames** come when your chips in a space change outside a game you're watching: an earned chip (the sampler;
  `earned_today` is then included), a cash-out, a prestige. Your own sockets only. (Apps may also refetch `/me`.)
- `error` frames answer a socket request that has no `op` (`open` of a table you can't see: `no-table`, `rig-hidden`;
  a malformed frame: `bad`; `sub` to a room you aren't in: `not-member`).

## Spaces (spec rev 2, §1.1)
- Every wallet, rank, table and chat card belongs to a **space** (the room's game space), kept by its **owner** (the
  server of the space's `m.room.create` sender). Views, `room` frames and `GET /rooms/{room}/tables` carry `space` +
  `owner`; the table header shows the space's avatar + name + owner (never the name alone).
- Ask `GET /rooms/{room}/space` on the owner your own `game_space` found; `wrong-server` (with `space` + `server`) is
  shown ("Couldn't confirm this room's space"), **never followed**. `no-space`: "Games live in spaces: start one from a
  room in a space." `unavailable`: try again later.
- Send the `space` you showed the person on `POST /wallet {space}`, `POST /rooms/{room}/tables {game, space, opts}`,
  `sit {space}` and `join {space}`: a different answer on the server = `409 space-changed` before any chip moves
  (refresh what you show). `GET /me?space=`, `/me/journal?space=`, `DELETE /wallet?space=`, `GET /ranks?space=` (or
  `?room=`). `wallet` and `rank` frames carry `space`; the session answer and `hello` list `wallets: [space…]`.

## Hold'em (`holdem/`)
- `status`: `lobby` (no hand yet) · `hand` · `pause` (between hands: `result` is set, the next deal at
  `result.next_at`) · `closed` (`closed.reason`: `host | idle | no-call | restart | off | end | space-changed | empty`;
  `empty` = everyone left, `space-changed` = the room's game space changed, §1.1).
- Seat `state`: `waiting` (seated, dealt in at the next hand) · `active` · `folded` · `allin` · `away` (two timeouts or
  "away"; dealt out, no blinds) · `out` (0 chips, no top-up today) · `leaving` (pressed Leave mid-hand: folds when the
  action reaches them, cashed out at the end of the hand). `cards` = how many cards a seat holds (0 or 2); `shown` only
  at a showdown.
- Money: `seats[].bet` = chips in front of that seat **this street**; `hand.pots` = chips gathered from earlier streets
  (`eligible` = seat numbers); `hand.total` = everything in the middle (pots + bets). Raise amounts are **TO** totals
  for the street. All-in = `raise.max` (or a call when `raise` is `null` and `call` ≥ your stack). An all-in short of a
  full raise is offered as `raise: {min: X, max: X}`.
- `result` (SETTLE → PAUSE): pots with winners and what each won (`paid` by seat), uncalled chips `returned`,
  `shown`/`best` per seat, `net` per person for the hand. A restart: `result.voided: true` + `closed.reason: restart`
  → the line "The dealer restarted: that hand was called off and everyone's chips went back."
- `you.can_deal` (the host, in the lobby only) = Deal is possible: at least two seated players with chips.
- `you.screens` = the kinds of your sockets that have this table open (`pad` among them = hide the cards on the
  computer, hold-to-peek). `you.at_cap` = show "At your cap: you'll prestige when you leave this table".
- Hand history: `GET /tables/{id}/hands` (your own cards only). Summary card: `GET /tables/{id}/summary`.

## The Rig (`rig/`)
- `status`: `lobby` · `round` · `end` (the table's rotation is over: `end.leaderboard`, `end.pit_boss`) · `closed`.
- `players[].role`: `null` (lobby) · `spinner` · `mechanic` · `sharp` · `railbird`. Roles are public; who holds which
  card is not (until the reveal).
- `round.phase`: `setup` (20 s) · `turn` (20 s) · `spin` · `land` (2 s) · `nudge` (4 s, Full) · `payout` · `reveal`
  (20 s). `deadline` is `null` while nothing is timed (spin, payout) and while `paused` (the Spinner disconnected:
  `paused.budget_ms` = what's left of the round's 45 s budget).
- `round.features` says what the preset allows (`mutes`, `nudge`, `whisper`, `patch`): hide what's off.
- `round.board` = the deck on the board; `state`: `open` (could be live) · `dead` (shown at the start) · `busted`
  (called right; `by` = its owner, `spin` = when) · `wrong` (called wrong; greyed). `refilled[].spin` = the turn in which a
  busted slot was Patched (the new card is live from that spin on: "slot refilled on spin n").
  `calls_left` + `call_used_this_spin` (≤ 1 Call per spin) decide whether Call is offered; Walk is offered from
  `spin >= walk_from` in TURN.
- `round.reels` = what the reels show now (LAND/NUDGE: after the cards; PAYOUT: final). `round.nudge`: `{open: true,
  deadline}` during the window, then `{open: false, reel, step}` if someone nudged (never who). `round.dial` = the
  Spinner's live dial (also pushed as `live` frames, ≤ 10 a second); `round.bet` = the bet once SPIN locked it.
- `history[]` = finished spins (final reels, payout, result, stamps `nudged | audited | called-right | called-wrong |
  refilled`; a Mute is never stamped).
- A **busted Mechanic** keeps the role `mechanic` with `busted: true` and `card: null` for the rest of the round (they
  play as a Sharp: Peek, Market, Nudge, Whisper), and `patch: {card, ok}` while a Patch is possible (Full, the table's
  Patch option on, before the next SPIN). A Patch makes `busted` false and `card` the new card.
- **Whispers and connectivity (launch-gate 11-19):** `players[].connected` is public, so when the whisperer is the only
  connected House member the Spinner can tell who wrote a Whisper. Both apps warn BEFORE sending, word for word: "You're
  the only House member here, so the Spinner will know this is from you." (`vectors/client-rules.json` `whisper_alone`).
- `round.paused.budget_ms` is a clock reading like `now`: it counts down without moving `vseq`.
- `players[].left` = left the table (their wagers stand until the reveal; no `you` any more). `players[].skipped` = their
  Spinner turn was skipped this table (not enough chips for a bankroll of 3).
- `you` by role (see `schema.json` `rigYou`): Spinner `whispers` (no authors); Mechanic `deal` (SETUP, until `kept`),
  `card` + bite, `mutes_left`/`armed`, `rake` (rake earned this round), `call_shares` (wrong-Call chips earned this round), `busted`, `patch` (the returned card when a Patch is possible); Sharp /
  Mechanic `peek`, `market`, `market_done`, `nudge_left`, `whisper_used`; Railbird only Nudge + Whisper.
- `round.audit` appears only in the Spinner's view (until the reveal). `round.reveal` appears only in REVEAL (sent
  after the settlement committed): `slots`, `mutes`, `nudges`, `calls`, `peeks`, `market`, `whispers` (with authors),
  `spins` (honest / after cards / final, touched, bit, rake by card), `up`, `net`, the `seed` (its SHA-256 =
  `seed_commit`). Finished rounds: `GET /tables/{id}/rounds/{r}`.

## The mock (code against it now; the real server answers the same contract)
```
node mock.mjs --port 8787            # then base http://127.0.0.1:8787/api/play/v1, socket ws://127.0.0.1:8787/api/play/v1/ws
```
- Plain Node 22, no install. On the share: `claude/minigames/mock/` (finds this folder by itself; `--views DIR`
  otherwise). In the server repo: `api/tinhat-api/play/tools/mock.mjs` (not shipped in the image). Loopback only, never expose it: any `user_id`
  signs in (the OpenID token isn't checked).
- Every room gets one Hold'em and one Rig table on first sight (`--empty` to start without). The first people to open
  a table become the fixture's players in order (the host's seat first), the rest watch; your mxid replaces the fixture
  person's everywhere in the views. `--rig-phone` = the owner's "Show The Rig in the phone apps" switch on.
- Acts are checked against the step's `moves` and `at`, answered with real acks (`stale`, `not-your-turn`,
  `bad-amount`, `host-only`, `phase`, `dup`), and move the table to the fixture's next step. LAND, NUDGE and the
  showdown pause move on by themselves.
- Mock-only controls (not part of the contract): a socket frame `{"t":"_mock", …}` or `POST /api/play/v1/_mock` with
  `{"table":ID,"go":"04-flop"|"next"|"prev"|"reset"}`, `{"table":ID,"as":"seat6"|"spectator"|"dee"…}`,
  `{"rank":{"u":MXID,"rank":3}}` (pushes a `rank` frame), `{"wallet":{"u":MXID,"balance":40}}`,
  `{"post":{"table":ID,"kind":"invite"}}`. `GET /api/play/v1/_mock` = tables, steps, who is who;
  `GET /api/play/v1/_mock/features` = the well-known flags it pretends.
- Spaces in the mock: every room's game space is `!sp<hash>:<the room's server>`, kept by the room's server; test
  rooms whose id starts with `!nospace` answer `no-space`, `!remote` answer `wrong-server` (`other.example`), `!unavail`
  answer `unavailable` (for `/space`, `/tables` and `sub`).
- Ranks in the mock: a lab account named `@<name>-testN:…` → N=1: 1, 2: 2, 3: 4, 4: 6, 5: 9, 6: 13 (every token look), others 0 unless set.
- The mock checks every frame it sends against `schema.json` (a failing frame is NOT sent; it prints `mock BUG`) and
  answers a client frame that doesn't match the schema (including a move's required fields) with
  `{"t":"error","code":"bad"}`: a cheap contract check for your client.
- What the mock does NOT simulate (its numbers come from the fixtures): a move that only changes your own panel
  (keep, Market, Mute, Whisper, Peek, sit/leave between hands) is acked but the view stays the step's; only the moves
  named in a step's `next` move the table on (LAND, NUDGE, PAYOUT, REVEAL, SETUP and the showdown pause move on by
  themselves); wallets don't follow the table's money; `/hands` and `/rounds/2` are the fixture answers (gated like the
  real ones: seated / a finished round only). `you.screens` IS live: it lists the kinds of your sockets that have the
  table open (`pad` when one authed with `client.pad: true`).
